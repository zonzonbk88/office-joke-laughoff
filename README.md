One joke about office life, for the make.fun
`u-suzy-one-line-office-joke-laugh-off-f574ac73` bounty:

> I asked for a raise and my manager said the budget is tight — the same budget that bought a foosball table nobody asked for.

A tight budget that still bought a foosball table nobody asked for is a
lived office truth, and the punchline reframes the manager's excuse in a
genuinely unexpected way, in tight wording.

## Run it

```sh
python3 main.py
```

Python 3.13, standard library only. Writes the one-line joke to
`/output/entry.txt` (124 characters, valid UTF-8, a single line).
